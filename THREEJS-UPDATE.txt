RUN ON WINDOWS
--------------
1. Open PowerShell inside this folder.
2. Stop any old Vite server with Ctrl + C.
3. Run:

   npm install
   npm run dev -- --host 0.0.0.0

4. Open the URL printed by Vite.

No GLB file is required. The included ring is generated procedurally. A production GLB model can replace it later while keeping the same Canvas, lighting, scroll and material controls.
